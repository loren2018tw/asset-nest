# 06: v6 位址登錄制

**What to build:** IPv6 網段的 IP 管理頁:只登錄與列出已指派的位址,提供「新增位址」;用途固定手動設定,不枚舉空閒位址。

**Blocked by:** 05 IP 指派(手動／保留)

**Status:** ready-for-agent

- [ ] v6 網段 IP 頁只列出已登錄位址,附「新增位址」入口
- [ ] 新增即指派(輸入位址+選資產/介面,流程同 05);可編輯與取消指派
- [ ] 用途固定為手動設定;不提供保留選項,亦無 pool 概念
- [ ] 不顯示任何空閒位址
- [ ] 後端整合測試涵蓋登錄、取消與 v6 結構檢查(合法 IPv6、同網段不重複)
