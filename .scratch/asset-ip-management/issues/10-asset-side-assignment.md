# 10: 資產端指派 IP（含移轉）

**What to build:** 從資產清單與資產編輯對話框的介面清單直接指派 IP；輸入 IP 後若已指派給其他介面，提示並在確認後將指派移轉到目前介面（v4/v6 皆支援，原子取消＋重新指派）。決策另立 ADR-0007。

**Blocked by:** 09 連線主機 MAC 參考（新增介面表單沿用其 MAC 提示）

**Status:** ready-for-agent

- [ ] 資產管理列表每列新增「指派 IP」按鈕；資產編輯對話框的介面列亦新增「指派 IP」按鈕（未儲存的資產／介面不顯示）
- [ ] 指派對話框：輸入 IP、選介面（或當場新增介面：名稱／MAC，含票 09 的連線主機 MAC 提示）、用途（手動／保留；無 MAC 時保留停用；保留可填 hostname）
- [ ] IP 已指派給其他介面時，提示目前指派對象（資產描述／位置、介面名稱／MAC），確認後移轉到目前介面
- [ ] 移轉為原子操作（單一交易內取消＋重新指派），不留歷程（見 ADR-0005）
- [ ] 結構規則阻擋：保留需介面有 MAC；同一介面在同一網段至多一位址；位址須落在某網段內（v4 另須為 host 且非池內）；介面須屬於該資產
- [ ] v6：登錄即指派；已登錄給其他介面時同樣提示移轉；用途固定手動設定
- [ ] 後端整合測試涵蓋指派、移轉（v4/v6）、各結構規則與不信任情境（介面不屬資產、位址不在網段內）
