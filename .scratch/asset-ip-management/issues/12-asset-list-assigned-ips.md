# 12: 資產清單「已指派 IP」欄與 IP／MAC 搜尋

**What to build:** 資產管理清單顯示每台資產的全部已指派位址（v4 先、v6 後，同列並排），並讓關鍵字搜尋能以 MAC 或已指派 IP 找到資產——補齊 spec §2.1 已定案、程式尚未實作的部分。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 資產清單新增「已指派 IP」欄，位置在「位置」欄之後；列出該資產所有已指派位址（跨介面、跨網段、v4／v6 並存）
- [ ] 每筆位址一格 chip、同列並排、過多自動換行；v4 在前、v6 在後，同地址族依位址數值排序；未指派顯示「—」
- [ ] 欄位為純顯示：不可點擊、不列入排序白名單、不顯示用途／hostname
- [ ] 關鍵字 `q` 以子字串、大小寫無關比對 MAC 與已指派位址（v4／v6）；與既有篩選（位置／廠牌／標籤）可組合
- [ ] 後端整合測試涵蓋：無指派、單筆、雙棧、多介面多筆、q 搜尋 MAC／IP／無結果；前端 typecheck／lint 全綠
