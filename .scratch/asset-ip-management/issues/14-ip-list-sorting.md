# 14: IP 清單標頭排序

**What to build:** IP 管理清單（v4 枚舉與 v6 登錄）的標頭可點擊排序，由伺服器端對符合篩選的全部位址排序後分頁。取捨已定案：v4 非 IP 欄排序採掃描後排序，成本與現行關鍵字搜尋同級，不設位址數上限。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 可排序欄位：IP（數值）、Gateway、狀態／用途、位置、指派對象；「衝突」「操作」不可排序
- [ ] 預設不變：未帶排序參數時為 IP 數值升冪；點擊切換 asc／desc；切換排序時回第 1 頁
- [ ] 狀態 asc 固定序「可用→池內→手動設定→保留」；指派對象依資產描述（不分大小寫）；同鍵以 IP 數值升冪決勝
- [ ] 依位置或指派對象排序時，未指派（空白）固定排在最後（asc、desc 皆然）
- [ ] 排序可與關鍵字／狀態篩選組合；v4（含出界指派列）與 v6 一致
- [ ] 無效 `sort`／`dir` 回 400（比照 `/assets` 慣例）
- [ ] 後端整合與單元測試涵蓋各欄、方向、空值、組合、無效參數；前端 typecheck／lint 全綠
