# 規格：CSV 匯出與網段匯入（資料重建）

- 狀態：已定案（2026-10-04），待實作。
- 詞彙依 `GLOSSARY.md`；網段 CSV 格式與寫入語意見 `docs/adr/0009`；資產匯出沿用 `docs/adr/0008` 的 14 欄格式；兩層驗證見 `docs/adr/0006`。

## 1. 範圍

### 1.1 本階段包含

- 資產清單「匯出」：以匯入範本 14 欄輸出目前搜尋／篩選／排序的資產（忽略分頁）。
- 網段設定「匯出」：輸出全部網段設定（含 pool、gateway、Kea subnet-id）。
- 網段設定「匯入」：CSV 批次新增網段；dry-run 預覽、全有全無、問題列報告。
- 重建流程：空庫（或刪除資料庫後）先匯入網段、再匯入資產。

### 1.2 本階段不含

- 更新既有資料：資產匯入與網段匯入皆只新增，不 upsert、不刪除。
- `.xlsx`、自動排程備份、IP 位址清單匯出、匯入歷程。

## 2. 網段 CSV 格式（權威文件：`docs/adr/0009`）

| # | CSV 標題 | 必填 | 格式與規則 |
|---|---------|------|-----------|
| 1 | 名稱 | 否 | 不強制唯一（雙棧可同名） |
| 2 | CIDR | **是** | 合法 CIDR；全系統唯一、不得與既有或檔內其他列重疊（含嵌套） |
| 3 | Gateway | 否 | 須在該 CIDR 內 |
| 4 | Kea subnet-id | 否 | 僅 IPv4；正整數；全系統唯一 |
| 5 | 位址池 | 否 | 僅 IPv4；以 `\|` 分隔多段，每段 `起點-終點`（例：`10.0.0.100-10.0.0.200\|10.0.0.250-10.0.0.253`）；各段須在 CIDR 內、彼此不重疊 |
| 6 | 備註 | 否 | |

- 標題列、編碼偵測（UTF-8／Big5）、大小與列數上限、引號規則、trim 規則：沿用 `docs/adr/0008`。
- v6 列的 Kea subnet-id 與位址池須留空；有值 → 錯誤列。

## 3. 網段匯入語意

- **只新增**：CIDR 已存在（檔內或既有）→ 錯誤列；與既有或檔內網段重疊 → 錯誤列。
- **全有全無**：任一列結構錯誤 → 整批不寫入。
- dry-run 預覽與正式匯入回應格式比照資產匯入（見 `asset-csv-import/spec.md` §5.2）；正式匯入於單一交易完成。
- 問題列報告：列號＋原始 6 欄＋原因，UTF-8 BOM，檔名 `網段匯入問題報告_YYYYMMDD.csv`。

## 4. 資產匯出

- 欄位與格式：與 `docs/adr/0008` 範本相同 14 欄（標籤以 `|` 串接、日期 `YYYY-MM-DD`、MAC 小寫冒號）。
- 一列一資產；介面與位址選取規則：
  1. 介面：有指派位址的介面中 id 最小者；若皆無指派，取 id 最小介面；無介面 → MAC／IPv4／IPv6／hostname 全空。
  2. IPv4／IPv6：所選介面的指派中，同族位址數值最小者；無 → 空。
  3. hostname：僅當匯出的 IPv4 為 reservation 時帶該筆 hostname；其餘為空。
- 套用目前搜尋／篩選（q／location／brand／tag）與排序；忽略分頁。
- 輸出：UTF-8 BOM；檔名 `資產匯出_YYYYMMDD.csv`；第一列為標題（不含範例列）。

## 5. API

| Method | Path | 說明 |
|---|---|---|
| GET | `/assets/export` | 同 `GET /assets` 查詢參數；回 `text/csv`（attachment） |
| GET | `/subnets/export` | 全部網段（v4 先、v6 後，同族依 CIDR 數值）；回 `text/csv`（attachment） |
| POST | `/subnets/import?dry_run=true|false` | multipart，檔案欄位名 `file`；回應比照資產匯入報告（`encoding`／`ignored_headers`／`summary`／`rows`／`committed`／`created={subnets}`） |

## 6. 操作界面

- 資產清單工具列新增「匯出」（icon `download`），位於「匯入」旁；點擊即下載目前條件的匯出檔。
- 網段設定工具列新增「匯出」「匯入」；匯入用對話框（三步：選檔 → 預覽 → 結果），比照 `AssetImportDialog`，含編碼顯示、忽略欄位提示、「只看問題列」切換、問題列報告下載。
- 匯出即下載，不需對話框。

## 7. 重建流程（文件化）

1. 停止服務，刪除 `asset-nest.db`（含 `-wal`／`-shm`）。
2. 啟動服務，等待遷移完成。
3. 網段設定 →「匯入」載入網段 CSV。
4. 資產管理 →「匯入」載入資產 CSV（`docs/adr/0008` 格式；網段須已存在）。

## 8. 決策出處

- `docs/adr/0009`：網段 CSV 格式與只新增語意（空庫重建用途、與資產匯入一致）。
- `docs/adr/0008`：資產 CSV 14 欄格式（匯出沿用）。
- `docs/adr/0006`：結構錯誤阻擋、語意警示提示。
- `GLOSSARY.md`：匯入／匯出／範本／問題列報告。
