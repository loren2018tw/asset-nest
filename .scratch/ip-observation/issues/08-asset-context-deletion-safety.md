# 08: 資產脈絡與回收防呆

**What to build:** 資產清單多一欄「最後可見」（可排序）；資產詳情顯示最後可見、介面 MAC 可點開觀測歷史；刪除資產與取消指派／刪除保留的確認框顯示最後可見與最後 MAC，避免回收其實還在線的位址。

**Blocked by:** 02 快速掃描與「最後可見」欄（核心）、06 觀測歷史對話框與匯出

**Status:** ready-for-agent

- [ ] 資產最後可見＝其已指派位址或介面 MAC 命中的現況列取最大值；清單與詳情皆回傳
- [ ] 資產清單支援 `sort=last_seen`（NULL 固定最後）
- [ ] 資產詳情顯示最後可見；介面 MAC 可開啟歷史對話框（重用票 06 元件）
- [ ] 刪除資產、取消指派／刪除保留的確認框顯示最後可見與最後 MAC（僅提示、不阻擋）
- [ ] 測試與 `pnpm lint:check`／`pnpm typecheck` 全綠
